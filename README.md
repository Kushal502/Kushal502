### About

I'm studying Computing Systems at Ulster University's London campus, currently in my second year. My coursework spans web development, server-side PHP and Java — but the part I keep going deeper on is **networking and security**: how traffic actually moves, what a TLS handshake really contains, and how to configure and verify a routed network from the CLI.

Everything below is coursework or personal work I've built and can talk through.

**Open to internships** — placement or summer, London or remote.
